OpenSpider

Häufige Fragen

Ist OpenSpider Open Source?

Ja. Der Quellcode ist unter Apache-2.0 veröffentlicht und auf GitHub zugänglich. Name und Logo sind von dieser Lizenz ausgenommen.

Wo liegen meine Crawl-Daten?

OpenSpider läuft lokal. Jeder Crawl wird als SQLite-Datei auf deinem Rechner gespeichert. Beim Crawlen werden die von dir gewählten Websites kontaktiert. Optionale externe Integrationen stellen Verbindungen zum jeweiligen Anbieter her. Integrierte KI-Dienste sind geplant und würden ebenfalls den jeweiligen Anbieter kontaktieren.

Brauche ich ein Konto?

OpenSpider bleibt ohne Konto nutzbar. Für optionale externe Dienste sind eigene Zugangsdaten beziehungsweise API-Schlüssel vorgesehen.

Welche Plattformen werden unterstützt?

Die Desktop-App zielt auf macOS und Windows. Linux x86_64 wird für Kern und CLI unterstützt; eine Linux-Desktop-App ist bewusst nicht vorgesehen. Hinweise zur CLI findest du im Handbuch. Das README erklärt das Bauen aus dem Quellcode.

Was bedeutet MCP?

Das Model Context Protocol verbindet einen KI-Agenten mit OpenSpider. Er kann damit beispielsweise Issues und URL-Details aus gespeicherten Crawls abfragen. Über das Menü „MCP“ verbindest du Claude Desktop, Claude Code, Codex oder Cursor mit einem Klick. Standardmäßig sind nur lesende Werkzeuge freigegeben. Mit der Option „Agent darf Crawls starten“ kann der Agent Crawls auch starten und ab beta.4 pausieren, fortsetzen und stoppen. Ein gestoppter Crawl bleibt beendet. MCP einrichten.

Kann ich die Beta schon herunterladen?

Ja. Die Installer der offenen Beta liegen auf GitHub Releases ↗; welche Datei du brauchst und was beim ersten Start zu beachten ist, steht auf der Beta-Seite.

Setzt diese Website Cookies oder Tracker ein?

Diese statische Website verwendet keine Cookies, Tracker, externen Schriftarten oder eingebetteten Dienste. Hinweise zur serverseitigen Verarbeitung stehen in der Datenschutzerklärung.

Wo steht die Installationsanleitung?

Das Benutzerhandbuch erklärt Gatekeeper, SmartScreen, stille MSI-/NSIS-Installation und das Entfernen von Benutzerdaten. Dort stehen auch die Befehle für Homebrew; winget ist ab Version 1.0 geplant und noch nicht verfügbar.

Sendet OpenSpider Telemetrie?

Die Update-Prüfung ist keine Telemetrie: Sie sendet nur Version, Betriebssystem und Architektur. GitHub sieht die IP-Adresse der Verbindung. Unter Einstellungen → Updates oder mit OPENSPIDER_DISABLE_UPDATE_CHECK=1 abschaltbar. Chromium lädt OpenSpider nur, wenn du es anforderst. Datenschutz der Updates.

Muss ich Chrome oder Chromium installieren?

Nur für JavaScript-Rendering. Chromium ist nicht im Installer enthalten. Auf Wunsch lädt OpenSpider eine geprüfte Version herunter (Konfiguration → Spider → Rendering, rund 200 MB, SHA-256-Prüfung); ein bereits installiertes Chrome funktioniert ebenfalls. Ohne JavaScript-Rendering ist kein Browser nötig. Chromium im Handbuch.

Warum warnt macOS oder Windows beim ersten Start?

Unter macOS fragt Gatekeeper einmal, ob du die aus dem Internet geladene App öffnen willst. Unter Windows kann SmartScreen bei einem neuen Zertifikat trotz gültiger Signatur warnen; prüfe über „Weitere Informationen“ den Herausgeber. Bei „beschädigt“, unbekanntem Herausgeber oder ungültiger Signatur nicht öffnen und Schutzfunktionen nicht abschalten. Ablauf im Handbuch.

Wie prüfe ich meinen Download?

Jedes Release enthält die Datei SHA256SUMS mit den Prüfsummen aller Dateien. Die Download-Seite zeigt die Befehle für macOS, Windows und Linux.

Gibt es OpenSpider über Homebrew, winget oder Docker?

Homebrew: Ja, unter macOS über den Tap wojcikdominik/homebrew-openspider mit dem Cask openspider@beta; die drei Befehle (Tap einbinden, Tap vertrauen, installieren) stehen im Handbuch. winget: geplant ab Version 1.0. Docker: Es gibt ein Dockerfile zum Selbstbauen für Linux-Server (CLI, Exporte, MCP, keine Weboberfläche), aber kein öffentliches Image. Docker im Handbuch.

Welche Sprachen hat die Oberfläche?

Deutsch und Englisch. Spanisch, Französisch und Italienisch kommen ab beta.4 als Beta-Übersetzungen hinzu; sie sind noch nicht von Muttersprachlern geprüft.

Zeigt OpenSpider, was nach einem Update neu ist?

Ab beta.4 ja: Nach einem Update zeigt die App einmal den Dialog „Neu in OpenSpider“ mit den Release-Notes, ohne Netzwerkzugriff. Hilfe → „Neuigkeiten“ öffnet ihn jederzeit. Details.

Wann erscheint Version 1.0?

Version 1.0 ist in Vorbereitung und noch nicht erschienen. Wer die Beta nutzt, bekommt sie als normales Update.

Wer kann an der Beta teilnehmen?

Alle, ohne Anmeldung: SEO-Freelancer, Inhouse-Teams und Agenturen. Testaufgaben und das Formular für deine Rückmeldung stehen auf der Beta-Seite.

Frequently asked questions

Is OpenSpider open source?

Yes. The source code is published under Apache-2.0 and is available on GitHub. The name and logo are excluded from this licence.

Where is my crawl data stored?

OpenSpider runs locally. Each crawl is saved as a SQLite file on your computer. Crawling contacts the websites you choose. Optional external integrations connect to their respective providers. Integrated AI services are planned and would also connect to their respective providers.

Do I need an account?

OpenSpider remains usable without an account. Optional external services are designed to use your own credentials or API keys.

Which platforms are supported?

The desktop app targets macOS and Windows. Linux x86_64 is supported for the core and CLI; a Linux desktop app is deliberately out of scope. See the user guide for CLI guidance and the README for building from source.

What does MCP mean?

The Model Context Protocol connects an AI agent to OpenSpider. For example, it can query issues and URL details from saved crawls. The “MCP” menu connects Claude Desktop, Claude Code, Codex or Cursor in one click. Only read tools are enabled by default. With the option “Agent may start crawls” the agent can also start crawls and, from beta.4, pause, resume and stop them. A stopped crawl stays ended. Set up MCP.

Can I download the beta yet?

Yes. The open beta installers are on GitHub Releases ↗; the beta page explains which file you need and what to expect at first launch.

Does this website use cookies or trackers?

This static website uses no cookies, trackers, external fonts or embedded services. Information about server-side processing is available in the privacy notice.

Where are installation instructions?

The user guide covers Gatekeeper, SmartScreen, silent MSI/NSIS setup and removing user data. It also lists the commands for Homebrew; winget is planned from version 1.0 and is not available yet.

Does OpenSpider send telemetry?

The update check is not telemetry: it sends only version, OS and architecture. GitHub sees the connection’s IP address. Disable checks in Settings → Updates or with OPENSPIDER_DISABLE_UPDATE_CHECK=1. OpenSpider downloads Chromium only when you ask for it. Update privacy.

Do I need to install Chrome or Chromium?

Only for JavaScript rendering. Chromium is not part of the installer. On request OpenSpider downloads a verified version (Configuration → Spider → Rendering, about 200 MB, SHA-256 check); an already installed Chrome works too. Without JavaScript rendering no browser is needed. Chromium in the user guide.

Why does macOS or Windows warn me at first launch?

On macOS, Gatekeeper asks once whether you want to open an app downloaded from the internet. On Windows, SmartScreen may warn about a new certificate despite a valid signature; check the publisher under “More info”. For “damaged”, an unknown publisher or an invalid signature, do not open the file and do not switch off protection. Steps in the user guide.

How do I verify my download?

Every release contains the file SHA256SUMS with the checksums of all files. The download page shows the commands for macOS, Windows and Linux.

Is OpenSpider available through Homebrew, winget or Docker?

Homebrew: yes, on macOS through the tap wojcikdominik/homebrew-openspider with the cask openspider@beta; the three commands (add the tap, trust it, install) are in the user guide. winget: planned from version 1.0. Docker: there is a Dockerfile to build yourself for Linux servers (CLI, exports, MCP, no web interface), but no public image. Docker in the user guide.

Which interface languages are available?

German and English. Spanish, French and Italian arrive from beta.4 as beta translations; they have not yet been reviewed by native speakers.

Does OpenSpider show what is new after an update?

From beta.4, yes: after an update the app shows a “New in OpenSpider” dialog with the release notes once, without network access. Help → “What’s new” opens it at any time. Details.

When will version 1.0 be released?

Version 1.0 is in preparation and has not been released yet. If you use the beta, you will receive it as a normal update.

Who can join the beta?

Everyone, without registration: SEO freelancers, in-house teams and agencies. Test tasks and the feedback form are on the beta page.

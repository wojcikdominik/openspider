Download & Installation

Systemvoraussetzungen

  • macOS: 13 (Ventura) oder neuer, Apple Silicon und Intel (ein Universal-DMG).
  • Windows: 10 ab Version 1809 oder 11, x64. Windows on ARM nutzt den x64-Installer unter Emulation. WebView2 wird bei Bedarf geladen.
  • Linux: nur Kern und Kommandozeile für x86_64 mit glibc, keine Desktop-App.
  • Hardware: mindestens 4 GB RAM, SSD empfohlen; für große Crawls 8–16 GB RAM.

Erster Start und Warnungen

Die macOS-App ist signiert und von Apple notarisiert; macOS fragt beim ersten Öffnen einmal nach (Gatekeeper). Die Windows-Installer sind signiert; SmartScreen kann bei einem neuen Zertifikat trotzdem warnen. Prüfe dann den Herausgeber und lass dich nicht zum Abschalten von Schutzfunktionen verleiten. Ablauf und Prüfbefehle stehen im Handbuch unter macOS und Windows, dort auch die stille Installation für Softwareverteilung.

Weitere Dateien

Die Schaltflächen oben laden versionslose Kopien (OpenSpider-macOS.dmg, OpenSpider-Windows-Setup.exe), bytegleich mit den versionierten Dateien desselben Releases. Jedes Release enthält außerdem folgende Dateien; VERSION durch die Version ersetzen (zum Beispiel 1.0.0-beta.3):

  • macOS 13+ · Universal-DMG: OpenSpider_VERSION_universal.dmg
  • Windows x64 · Setup pro Benutzer (NSIS): OpenSpider_VERSION_x64-setup.exe
  • Windows x64 · MSI pro Rechner für Softwareverteilung: OpenSpider_<build-version>_x64_<language>.msi (exakten Namen aus dem Release übernehmen; MSI kann eine numerische Produktversion verwenden)
  • Kommandozeile: openspider_VERSION_darwin-universal.tar.gz (macOS), openspider_VERSION_windows-x86_64.zip (Windows), openspider_VERSION_linux-x86_64.tar.gz (Linux x86_64, glibc)
  • Prüfsummen: SHA256SUMS. Nur für automatische Updates der App: latest.json, latest-beta.json, *.app.tar.gz und *.sig.

URL-Muster: https://github.com/wojcikdominik/openspider/releases/download/vVERSION/DATEINAME

Windows on ARM verwendet den x64-Installer unter Emulation, keinen nativen ARM-Build. Linux unterstützt nur Kern und CLI. Linux-Desktop, .deb/.rpm und arm64-Releases sind nicht unterstützt.

SHA-256 prüfen

SHA256SUMS liegt im selben GitHub-Release und enthält die Prüfsummen aller Release-Dateien, auch der versionslosen Kopien (eine Zeile je Datei: Prüfsumme, zwei Leerzeichen, Dateiname). Lade die Datei und SHA256SUMS aus demselben Release in denselben Ordner und prüfe sie. Bei Abweichung nicht installieren, sondern neu laden.

# macOS (im Ordner mit DMG und SHA256SUMS)
grep ' OpenSpider-macOS.dmg$' SHA256SUMS | shasum -a 256 -c -
# Linux (Archiv und SHA256SUMS zusammen ablegen)
sha256sum --ignore-missing -c SHA256SUMS
# Windows PowerShell: Wert berechnen und mit der Zeile in SHA256SUMS vergleichen
(Get-FileHash .\OpenSpider-Windows-Setup.exe -Algorithm SHA256).Hash.ToLower()
Select-String -Path SHA256SUMS -Pattern 'OpenSpider-Windows-Setup.exe'

Unter macOS muss „OK“ erscheinen. Unter Linux prüfen, dass das gewählte Archiv tatsächlich als OK ausgegeben wird; --ignore-missing überspringt fehlende Dateien. Unter Windows müssen beide Werte übereinstimmen. Prüfsummen belegen die Unversehrtheit der Datei und ersetzen keine Signaturprüfung; die Herkunft belegen die Signaturen (Befehle im Handbuch).

Chromium

Chromium für JavaScript-Rendering ist nicht im Installer enthalten. Die App lädt auf Wunsch eine geprüfte Version herunter (Konfiguration → Spider → Rendering, rund 200 MB, SHA-256-Prüfung); ein installiertes Chrome funktioniert ebenfalls. Ohne JavaScript-Rendering brauchst du keinen Browser. Details im Handbuch.

Docker (Server)

Für eigene Server gibt es ein Dockerfile für Linux x86_64, aus dem du ein Container-Image mit CLI, Exporten, geplanten Läufen und MCP über STDIO baust, ohne Weboberfläche: Ergebnisse sind Dateien und Crawl-Dateien für die Desktop-App. Ein öffentliches, fertiges Image gibt es nicht; du baust es selbst aus dem Repository im Stand des Release-Tags (Ordner packaging/docker). Selbstbau, Ordner und Beispiele für Crawl, Vergleich, cron und MCP stehen im Handbuch.

Homebrew und winget

Homebrew: Ein eigener Tap mit dem Cask openspider@beta für macOS folgt in Kürze und ist noch nicht veröffentlicht; bis dahin das DMG verwenden. winget: geplant ab Version 1.0, noch nicht verfügbar; bis dahin Setup oder MSI verwenden. Stille Installation, SmartScreen, Gatekeeper und Deinstallation stehen im Handbuch.

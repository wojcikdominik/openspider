First open beta. Please send feedback via Help → "Send feedback…" or https://openspider.de/en/beta/.

- Desktop app for macOS (Apple silicon and Intel, signed and notarised) and Windows x64 (signed with Azure Artifact Signing).
- Automatic update check (can be switched off) with download in the background; installation at once or on quit, never during a running crawl.
- Smoother live crawl: shared, throttled counting for the overview, issues and filters; the overview only redraws changed rows.
- "Top issues" and "Findings" load quickly after a crawl ends; pause, resume and stop keep the crawl file clean.
- Old crawls and settings are carried over when opened.
- Known: JavaScript rendering uses an installed Chrome in this beta; the download on request follows with beta.2.

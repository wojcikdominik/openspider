## Auslegungen und offene Fragen an die Spec

1. **„Kandidat 1“ vs. Antwortreihenfolge (AI-070/AI-071):** Gespeichert wird in Antwortreihenfolge (alle Runden fortlaufend);
   `Suggestion 1` ist der **gewählte** Kandidat (erster gültiger nach dem Nachlauf, sonst der mit den wenigsten Verstößen),
   danach die übrigen in Antwortreihenfolge. Nur so erfüllen sich „in der Reihenfolge der Antwort gespeichert“ und „Y ist
   Kandidat 1“ zugleich.
2. **Spaltennamen Meta (AI-072 „analog“):** `Meta Description Suggestion k …`, `Meta Description Suggestion Status/Violations`,
   `Meta Description Review Status`, `Accepted Meta Description`; für Titles wie in AI-071 `Review Status`/`Accepted Title`.
   Zusätzlich je Kandidat `… Suggestion k Valid` (AI-075 „Kennzeichnung je Kandidat“) und `… Suggestion Provisional` (AI-071).
3. **Standard-Geltungsbereich ∩ S:** Die Problemfilter werden auf S (interne HTML-200-URLs, indexierbar) beschränkt; eine
   noindex-Seite mit fehlendem Title bekommt keinen Vorschlag.
4. **Dubletten auch für Meta Descriptions** (AI-075 (3) „bzw. Werten anderer URLs“): beide Stufen wie bei Titles.
